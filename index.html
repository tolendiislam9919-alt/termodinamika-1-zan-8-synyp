Газдың және будың жұмысы

Газ қалай жұмыс жасайды? Жылу қайда жұмсалады? Неге «мәңгі қозғалтқыш» жасау мүмкін емес?

«Тайтөбе ауылының жалпы орта білім беретін мектебі» КММ · 8-сынып · мұғалім Төленді И.Н.

Проблемалық жағдаят · стоп-кадрАвтокөлік қалай жүріп келеді?

Алдымен анимацияны көрейік: ▶ Бастау.

Жағдаят

Автокөлік тас жолмен бірқалыпты жүріп келеді. Оны ешкім итермейді, жел де соқпайды. Ал ауаның кедергісі мен үйкеліс оны үнемі тежейді.
Автокөлікті не қозғалтып келеді? Қандай күш?

Жаңа тақырып · газдың жұмысыҚозғалтқыштың ішіне үңілейік

Формула қайдан шықты?

① Ыстық газ поршеньге F = pS күшпен әсер етеді (p – газ қысымы, S – поршень ауданы)
② Поршень Δh-қа жылжиды, газ жұмыс жасайды: A = F·Δh
③ F-тің орнына pS қоямыз: A = pSΔh
④ SΔh = ΔV — газ көлемінің өзгерісі
⑤ Газдың жұмысы:  A = p·ΔV
Газ ұлғаяды: ΔV > 0 → A > 0. Газ сығылады: ΔV < 0 → A < 0. Сыртқы күштердің газға жасаған жұмысы: A′ = −A.

Қысым p
Көлем өзгерісі ΔV

Үй тапсырмасын тексеру · өткенді қайталауМиға шабуыл

Нөмірді таңда → сұрақ ашылады → жауап бер → тағы бір басу – дұрыс жауап. Бүгінгі жаңа заңға қажет білімдерді еске түсірейік.

Оқу мақсаты 8.3.2.17Бүгін не үйренеміз?

Термодинамиканың бірінші заңын түсіндіру; газдың жұмысын есептеу.

Барлық оқушылар

ішкі энергияны өзгертудің екі тәсілін атайды; газдың жұмысының формуласын A = pΔV біледі.

Көптеген оқушылар

бірінші заңды Q = ΔU + A түрінде жазып, есептер шығарады.

Кейбір оқушылар

адиабаттық үдерісті және мәңгі қозғалтқыштың мүмкін еместігін бірінші заң арқылы түсіндіреді.

Бағалау критерийлері

  • ішкі энергияны өзгертудің екі тәсілін сипаттайды;
  • газдың жұмысын A = pΔV формуласымен есептейді;
  • термодинамиканың бірінші заңын есеп шығаруда қолданады;
  • газдың жұмысы A мен сыртқы күштердің жұмысы A′ айырмашылығын түсіндіреді.

Виртуалды зертхана · энергияның сақталу заңыТермодинамиканың бірінші заңы

Бір күйден екінші күйге ауысқан дененің ішкі энергиясының өзгерісі дене алған жылу мөлшері мен сыртқы күштердің жұмысының қосындысына тең:
ΔU = Q + A′
A′ = −A болғандықтан: газға берілген жылу оның ішкі энергиясының өзгерісіне және газдың жұмысына жұмсалады:
Q = ΔU + A

Зертханада тексер

1) Поршень бекітулі: газ қыздырылса A = ? Жылу қайда кетеді?
2) Поршень еркін: Q қалай бөлінеді?
3) Жылу оқшауланған (Q = 0): поршеньді жіберсек, газ неге суиды?
Адиабаттық үдеріс – газдың сыртқы ортамен жылу алмасусыз (Q = 0) бір күйден екінші күйге өтуі. Мысалы: жоғары көтерілген ауа ұлғайып, суиды → бұлт түзіледі.

Бірінші заң және бірінші ретті мәңгі қозғалтқыш · стоп-кадр«Мәңгі» дөңгелек мәңгі айнала ма?

ХХ ғасырдың басында Лос-Анджелесте жарнама үшін осындай дөңгелек орнатылған. Оң жақтағы шарлар осьтен алыс, сол жақтағылар жақын — «дөңгелек өздігінен айнала береді» деп ойлаған. ▶ Итеріп жіберу.

Мәңгі қозғалтқыш

Мәңгі қозғалтқыш – отын немесе басқа энергия қорын жұмсамай-ақ механикалық жұмыс жасай алатын қозғалтқыш. Ол үшін Q = 0, сонда бірінші заң бойынша A = −ΔU.
