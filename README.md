# Термодинамиканың бірінші заңы. Газдың және будың жұмысы — 8-сынып

Интерактивті слайд-зертхана (физика, 8-сынып, §13, оқу мақсаты 8.3.2.17).
Мұғалім: Төленді И.Н., «Тайтөбе ауылының жалпы орта білім беретін мектебі» КММ.

## Ашу
- Компьютерде: `index.html` файлын браузерде ашу (бір файл, интернет қажет емес).
- GitHub Pages қосылғаннан кейін: `https://<пайдаланушы>.github.io/<репозиторий>/`

## Басқару
- ← → немесе PageUp / PageDown — беттер
- F — толық экран, T — тақтаны жасыру/шығару
- `#N` — N-бетке тікелей өту (мысалы `.../#3`)
